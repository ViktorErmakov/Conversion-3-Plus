| Консоль | Что это | Откуда подсказки |

## #44. Тесты

YAxUnit. Хост консоли и вкладки, где консоль уже стоит: XDTO и XML, включая конвертацию, ПОД, алгоритмы, ПКО, запросы, ПКПД и ПКС. Проверяем, что редактор на форме собрался и метаданные загрузились. Методы API самой консоли не проверяем.

## Паритет консоли

У каждого пункта: что видит разработчик правил, зачем это при обмене, какой вызов консоли, у кого из трёх это есть.

- Закладки строк на время открытой формы: `addBookmark`, `getBookmarks`, `goNextBookmark`, `goPreviousBookmark`. Команды на нашей панели, контекстное меню редактора не дописываем. Есть у бустера.
- Подсветка правок с момента открытия: `setOriginalText` кладёт исходный текст, редактор рисует виджет изменений. Режим `compare` для двух произвольных текстов не используем. Есть у бустера.
- Английские подписи параметров обработчика, когда `ЯзыкПодсказок = en`. Наши строки в том же JSON подсказок. Переключение встроенного языка редактора уже делает `switchLang`. Есть у бустера.
- Выбор релиза подсказки, если у конвертации их несколько. Реквизит формы и тот же `EVENT_GET_METADATA`. По умолчанию XDTO — `Конфигурация`, XML — сторона обработчика. Есть у TipsInCD3.
- Страница единственного заполненного обработчика. Пустые обработчики не активировать. Если заполнен один — открыть его страницу. Логика формы, к консоли не обращается. Есть у бустера.

Методы общих модулей, объекта и менеджера берутся из `Расш1_ТекстыМодулей`. Отдельная задача появится только если по факту не всплывают методы менеджера или объекта: тогда добрать их в тот же регистр, без разбора исходников на лету.

## Не делаем

- Текст справочника `Запросы` в режиме `bsl_query`. В поле бывает код, консоль остаётся в режиме `bsl`. Платформенный конструктор по-прежнему закрыт [#28](https://github.com/ViktorErmakov/Conversion-3-Plus/issues/28).
- Два метода, которые TipsInCD3 вшивает в `bsl_console`.
- Свой разбор типов локальных переменных сверх того, что редактор уже делает по `Новый`, присваиванию и результату метода.
- F12 внутрь текста чужого модуля. `parseMetadataModule` даёт список экспортных методов в подсказке. `goToFuncDefinition` ищет процедуру только в текущем тексте. `EVENT_GET_DEFINITION` сообщает имя, место в чужом модуле редактор не принимает.
